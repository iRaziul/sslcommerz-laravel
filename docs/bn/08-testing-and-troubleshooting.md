## 🌐 লোকালহোস্টে IPN / Webhooks পরীক্ষা করা

SSLCommerz সার্ভার আপনার কম্পিউটারের লোকাল `http://localhost:8000` অ্যাড্রেসে সরাসরি রিকোয়েস্ট পাঠাতে পারে না। লোকাল ডেভেলপমেন্টের সময় IPN টেস্ট করার নিয়ম:

### Ngrok ব্যবহার করে

১. আপনার লারাভেল অ্যাপ্লিকেশন চালু করুন:
   ```bash
   php artisan serve
   ```
২. আলাদা টার্মিনালে ngrok দিয়ে পোর্ট 8000 এক্সপোজ করুন:
   ```bash
   ngrok http 8000
   ```
৩. ফরোয়ার্ডিং HTTPS URL-টি কপি করুন (যেমন: `https://a1b2-3c4d.ngrok-free.app`)।
৪. আপনার `.env` ফাইলে `APP_URL` পরিবর্তন করুন:
   ```env
   APP_URL=https://a1b2-3c4d.ngrok-free.app
   ```
৫. এখন SSLCommerz আপনার লোকালহোস্টের IPN রাউটে সফলভাবে রিকোয়েস্ট পাঠাতে পারবে।

## 🛠️ সাধারণ সমস্যা ও সমাধান (Troubleshooting)

### ১. রিডাইরেক্ট হওয়ার পর `419 Page Expired` এরর
- **কারণ**: লারাভেলের CSRF / `PreventRequestForgery` (লারাভেল ১৩) মিডলওয়্যার SSLCommerz থেকে আসা বাহ্যিক ক্রস-অরিজিন POST রিকোয়েস্ট ব্লক করে দিচ্ছে।
- **সমাধান**: রাউট এক্সেম্পট করুন:
  ```php
  // লারাভেল ১৩ (bootstrap/app.php)
  $middleware->preventRequestForgery(except: ['sslcommerz/*']);

  // লারাভেল ১১ ও ১২ (bootstrap/app.php)
  $middleware->validateCsrfTokens(except: ['sslcommerz/*']);

  // লারাভেল ১০ (app/Http/Middleware/VerifyCsrfToken.php)
  protected $except = ['sslcommerz/*'];
  ```

---

### ২. `SslcommerzException: SSLCommerz store credentials are not set.`
- **কারণ**: `.env` ফাইলে `SSLC_STORE_ID` অথবা `SSLC_STORE_PASSWORD` দেওয়া হয়নি।
- **সমাধান**: `.env` ফাইলে সঠিক ক্রেডেনশিয়াল দিন এবং কনফিগ ক্যাশ ক্লিয়ার করুন:
  ```bash
  php artisan config:clear
  ```

---

### ৩. `Route [sslc.success] not defined.`
- **কারণ**: `config/sslcommerz.php` ফাইলে নির্ধারিত রাউট নামের সাথে `routes/web.php`-এর রাউট নামের অমিল রয়েছে।
- **সমাধান**: রাউটের নাম ঠিক রাখুন:
  ```php
  Route::post('success', [PaymentController::class, 'success'])->name('sslc.success');
  ```

---

### ৪. `validatePayment()` মেথড `false` রিটার্ন করছে
- **চেক ১: `val_id` অনুপস্থিত**: রিকোয়েস্টে `$request->input('val_id')` রয়েছে কিনা নিশ্চিত হোন।
- **চেক ২: টাকার পরিমাণ অমিল**: `validatePayment()` মেথডে দেওয়া টাকার পরিমাণের সাথে ডাটাবেজের অর্ডার অ্যামাউন্ট মিল রয়েছে কিনা দেখুন।
- **চেক ৩: কারেন্সি কোড**: BDT ছাড়া অন্য কারেন্সি হলে কারেন্সি প্যারামিটার পাস করুন:
  ```php
  Sslcommerz::validatePayment($payload, $tranId, $amount, 'USD');
  ```

---

### ৫. কাস্টমার তথ্যে ত্রুটি বা পেমেন্ট শুরু না হওয়া
- **কারণ**: SSLCommerz-এ কাস্টমারের নাম, ইমেইল, ফোন এবং ঠিকানা বাধ্যতামূলক।
- **সমাধান**: `setCustomer()` মেথডে সবগুলো ফিল্ড সঠিকভাবে পাস করুন:
  ```php
  Sslcommerz::setCustomer(
      name: $user->name ?? 'Customer',
      email: $user->email ?? 'customer@example.com',
      phone: $user->phone ?? '01700000000',
      address: $user->address ?? 'Dhaka, Bangladesh'
  );
  ```
